# LEGAL-PRIVACY — Privacy Policy

Kebijakan privasi sesuai UU PDP dan regulasi global.

---

## Data Collection

### We DO Collect:
- Email address and username (for account)
- Password hash (for authentication)
- License key and installation ID
- Usage analytics (anonymous, optional)
- Error logs and crash reports

### We DO NOT Collect:
- ❌ User queries/chat content (stored only locally)
- ❌ API keys (stored only in user's environment)
- ❌ Knowledge base documents (user's responsibility)
- ❌ Sensitive personal information
- ❌ Behavioral tracking/cookies

---

## Data Usage

- **Verify identity** → Authentication
- **Provide service** → Access control, licensing
- **Improve service** → Anonymous analytics
- **Legal compliance** → Required by law
- **Support** → Help troubleshooting

---

## Data Sharing

We only share data with:
1. **LLM Providers** → Your queries sent (you choose provider)
2. **License Server** → Installation ID only
3. **Legal requirements** → If required by law

---

## Data Retention

- **Account data** → Until account deleted
- **Queries** → Never stored (except in your local DB)
- **License logs** → 1 year
- **Error logs** → 30 days

---

## User Rights (UU PDP)

You have the right to:
- [ ] Access your data
- [ ] Correct inaccurate data
- [ ] Delete your account
- [ ] Data portability
- [ ] Opt-out of analytics

Request at: privacy@paugeran.dev

---

## Security Measures

- ✅ HTTPS/TLS for all communication
- ✅ Password hashing (Argon2)
- ✅ API key isolation
- ✅ License encryption
- ✅ No sensitive data in logs

---

## Policy Changes

Changes notified 30 days in advance. Continued use = acceptance.
